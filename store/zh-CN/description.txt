WhisPaste 可在任何 Windows 应用中，把你的语音直接转为光标处的文字。按下快捷键，开口说话，即可完成。无需复制粘贴，无需切换窗口。

无论你在哪里打字都能使用：Outlook、Teams、Word、VS Code、Chrome、Slack 以及其他所有应用。

🔒 你的语音留在你的电脑上
Whisper（三种模型大小，支持 99 种语言）和快速的 Parakeet 引擎（约 25 种欧洲语言，仅使用 CPU）完全在你的电脑上转写。默认情况下，转写完成后不保留录音。显卡可以加速 Whisper，但从来不是必需的。模型只需一次性下载，之后无需网络连接即可转写。使用 OpenAI 或 Deepgram 的云端转写是可选的，使用你自己的 API 密钥；音频直接发送给服务商，从不经过 WhisPaste 的服务器。无需账户。

✨ 智能模式（可选）
在粘贴前清理口头语和标点、缩短文本，或将其翻译成七种语言。可以使用本地 AI 模型运行，也可以通过 OpenAI 并使用你自己的密钥运行。在任何应用中选中文本，说出需要如何修改，WhisPaste 就会原地改写。

📋 历史记录、笔记与导出
每条转写都保存在本地并可搜索。可添加标签、置顶、归档、合并，并导出为 TXT、Markdown、JSON、CSV 或 Word。PIN 锁可保护历史记录的隐私。笔记和快速笔记可将较长的想法集中保存在一处。

⌨️ 语音片段与你自己的词汇
说出触发词，WhisPaste 即可插入完整文本：签名、问候语、你每天都会输入的短语。交互式片段会逐个字段填写模板。自定义词汇和替换规则可让人名和行话准确呈现。

🎛️ 为日常工作而设计
切换或按住说话 · 带可选实时预览的实时浮层 · 悬浮按钮 · 屏幕边缘的剪贴板侧边栏 · 系统托盘和开机自启 · 界面语言：英语、德语、希伯来语、俄语、西班牙语和巴西葡萄牙语（中文界面尚未提供）
