# Social and support logos (Übersicht "Mitmachen", Hilfe › Unterstützung)

Brand marks used only to name the project's own channels (GitHub, YouTube, X) and the support providers the
project uses (PayPal, Ko-fi, Buy Me a Coffee, GitHub Sponsors).

| File | Source | License / basis |
| --- | --- | --- |

| `x-logo.svg` | Path from simple-icons 14.13.0 (`icons/x.svg`) | CC0 (simple-icons); the mark is X's, used in black or white |
| `youtube-logo.svg` | Frame and play mark from simple-icons 14.13.0 (`icons/youtube.svg`), frame in YouTube red `#FF0000`, play mark in white | CC0 (simple-icons); the colors follow YouTube's brand resources |
| `paypal-logo.svg` | Path from simple-icons 14.13.0 (`icons/paypal.svg`) | CC0 (simple-icons); the mark is PayPal's, see [PayPal media resources](https://newsroom.paypal-corp.com/media-resources) |
| `kofi-logo.svg` | Path from simple-icons 14.13.0 (`icons/kofi.svg`) | CC0 (simple-icons); the mark is Ko-fi's, see [Ko-fi brand assets](https://more.ko-fi.com/brand-assets) |
| `buymeacoffee-logo.svg` | Path from simple-icons 14.13.0 (`icons/buymeacoffee.svg`) | CC0 (simple-icons); the mark is Buy Me a Coffee's |

| `githubsponsors-logo.svg` | Path from simple-icons 14.13.0 (`icons/githubsponsors.svg`), the GitHub Sponsors heart | CC0 (simple-icons); the mark is GitHub's, per [GitHub's logo guidelines](https://brand.github.com/foundations/logo) |

The marks are shown unaltered in shape, with the standard black/white (GitHub, X) or brand red (YouTube) colors; no
other colors, effects or shadows. The app tints the black/white marks to the theme's text color.

The support marks sit on a tile in the provider's colour (`WpBrandTokens`, from `design-tokens/app.tokens.json`) and are
tinted to the tile's ink (white on PayPal blue, navy on the other three) so the contrast holds; their shape is unaltered.
