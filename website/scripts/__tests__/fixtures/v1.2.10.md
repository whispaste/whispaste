### Highlights
- WhisPaste now operates as a native application, providing a smoother and more responsive experience across all platforms, including Windows and macOS.
- The user interface has been completely revamped with a modern design, featuring warm gradients, frosted glass effects, and improved accessibility.
- A new recording pill overlay displays an elegant status bar during dictation, while a floating button allows for easy recording access with a context menu for quick actions.
- The macOS app now includes a native ARM64 DMG for easier installation, and the menu bar icon functions correctly across all layouts.
- The history detail editor now supports standard editing operations without interference from keyboard shortcuts, enhancing usability.

### Verbesserungen
- The app's stability has been enhanced, eliminating crashes when quitting via the floating button or tray icon.
- All data is now securely stored in a local database, improving data management and privacy.
- The app includes over 469 automated tests, ensuring a reliable and consistent user experience.
