### Highlights
- WhisPaste underwent a complete rewrite, now functioning as a native application with a truly cross-platform experience across Windows, macOS, Linux, iOS, and Android.
- Users now enjoy a sleek and elegant recording pill overlay during dictation, featuring a progress ring for better visibility.
- The floating button has been enhanced with a context menu that allows quick access to start recording, view history, open settings, or quit the app.
- The macOS version now ships as a native ARM64 DMG, ensuring better compatibility and performance on Apple devices.
- Keyboard shortcuts in the history detail editor now work correctly, allowing for smooth text editing without interruptions.

### Verbesserungen
- The app's stability improved significantly with the removal of the previous Go backend, eliminating related dependencies.
- A crash that occurred when quitting via the floating button context menu or tray icon has been resolved, enhancing the overall user experience.
- Mac App Store screenshots now accurately reflect the app's design with the correct resolution and authentic macOS window features.
