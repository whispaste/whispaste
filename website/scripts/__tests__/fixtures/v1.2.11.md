### Highlights
- WhisPaste underwent a complete rewrite and is now a native application, providing a smoother experience across all platforms, including Windows and macOS.
- The user interface was enhanced with a unified design system, featuring warm gradients, frosted glass effects, and improved accessibility.
- A new recording pill overlay was introduced, offering a slim status bar during dictation that includes a progress ring.
- The floating button now includes a context menu, allowing easy access to start recording, view history, open settings, or quit the app.
- The history detail editor was improved, ensuring that standard editing operations work correctly without interference from keyboard shortcuts.

### Verbesserungen
- The macOS app now ships as a native ARM64 DMG, simplifying the installation process with direct download and Gatekeeper instructions.
- Crashes during quitting were resolved, ensuring a stable exit when using the floating button context menu or tray icon.
- The app now features accurate screenshots for the Mac App Store, reflecting the authentic macOS window design.
