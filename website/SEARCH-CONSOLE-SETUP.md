## 1. Google Search Console

### Register Property

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Click **Add property**
3. Select **Domain** and enter: `whispaste.de`
   - Requires DNS TXT record verification (preferred — covers all subdomains)
   - Alternative: **URL prefix** → `https://whispaste.de/`

### Verify Ownership

**Option A — HTML Meta Tag** (easiest)

1. Google provides a unique verification code
2. Add the meta tag to `website/src/layouts/Layout.astro` inside `<head>`:

   ```html
   <meta name="google-site-verification" content="YOUR_CODE_HERE" />
   ```

3. Deploy the site and click **Verify** in Search Console

**Option B — HTML File Upload**

1. Download the verification HTML file from Search Console
2. Place it in `website/public/` (Astro copies `public/` to build output as-is)
3. Deploy and verify

> **⚠️ The verification code is unique per Google account.** It cannot be pre-configured in the repository.

### Submit Sitemap

1. In Search Console → **Sitemaps** (left sidebar)
2. Enter: `https://whispaste.de/sitemap-index.xml`
3. Click **Submit**

### Request Initial Indexing

1. In Search Console → **URL Inspection**
2. Enter: `https://whispaste.de/`
3. Click **Request Indexing**
4. Repeat for key pages: `/impressum/`, `/privacy/`, `/datenschutz/`

Pages typically appear in Google within **1–7 days**.

### Monitor

| Report | What to look for |
|---|---|
| **Pages** | Crawl errors, excluded pages, indexing issues |
| **Core Web Vitals** | LCP < 2.5s, INP < 200ms, CLS < 0.1 |
| **Mobile Usability** | Tap target sizes, viewport configuration |
| **Enhancements** | Structured data validation (SoftwareApplication, FAQPage) |

## 2. Bing Webmaster Tools

1. Go to [Bing Webmaster Tools](https://www.bing.com/webmasters)
2. Sign in and add `https://whispaste.de`
3. You can import from Google Search Console (fastest setup)
4. Submit sitemap: `https://whispaste.de/sitemap-index.xml`

Bing also powers **DuckDuckGo**, so this covers both search engines.

## 4. SEO Best Practices Reference

### Content

- **Title tags**: 50–60 characters, primary keyword near the front
- **Meta descriptions**: 120–160 characters, include a call to action
- **H1**: One per page, matches the page's primary topic
- **Internal linking**: Link between related pages (e.g., FAQ → Privacy)
- **Content freshness**: Update the page when major app features change

### Technical

- **Page speed**: Target LCP < 2.5s (static Astro site should exceed this easily)
- **Mobile-first**: All layouts must work at 320px width minimum
- **HTTPS**: Enforced by GitHub Pages + custom domain
- **No duplicate content**: Canonical URLs prevent this
- **Image optimization**: Use WebP/AVIF where possible, lazy-load below-fold images
- **Minification**: Astro handles CSS/JS minification at build time

### Structured Data

- **SoftwareApplication**: Name, description, OS, offers (free), download URL
- **FAQPage**: All FAQ questions/answers — enables rich snippets in SERP
- **Future**: Consider `VideoObject` if a demo video is added to the page

### Monitoring Cadence

| Task | Frequency |
|---|---|
| Check Search Console for errors | Weekly |
| Review Core Web Vitals | Monthly |
| Validate structured data | After content changes |
| Test OG image rendering | After image/brand changes |
| Update sitemap | Automatic at build time |
