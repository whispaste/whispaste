# Google Search Console Setup — WhisPaste Landing Page

## Prerequisites

- A Google account
- Access to the GitHub Pages repository settings (for verification)
- The WhisPaste landing page deployed at `https://whispaste.github.io/whispaste/`

## Step 1: Register Property

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Click **Add property**
3. Select **URL prefix** and enter: `https://whispaste.github.io/whispaste/`
4. Click **Continue**

> **Note:** Domain-level property verification requires DNS access, which is not available for `github.io` subdomains. Use the URL prefix method instead.

## Step 2: Verify Ownership

### Recommended: HTML Meta Tag

1. Google will provide a unique verification code
2. Add the meta tag to `website/src/layouts/Layout.astro` inside `<head>`:

   ```html
   <meta name="google-site-verification" content="YOUR_CODE_HERE" />
   ```

3. Deploy the site and click **Verify** in Search Console

### Alternative: HTML File Upload

1. Download the verification HTML file from Search Console
2. Place it in `website/public/` (Astro copies `public/` files to the build output as-is)
3. Deploy and verify

> **⚠️ The verification code is unique per Google account.** It cannot be pre-configured in the repository. Each developer must obtain their own code from Search Console.

## Step 3: Submit Sitemap

1. In Search Console, go to **Sitemaps** (left sidebar)
2. Enter the sitemap URL: `https://whispaste.github.io/whispaste/sitemap-index.xml`
3. Click **Submit**

The sitemap is auto-generated by `@astrojs/sitemap` during each build — no manual maintenance needed.

## Step 4: Request Indexing

1. In Search Console, go to **URL Inspection** (left sidebar)
2. Enter: `https://whispaste.github.io/whispaste/`
3. Click **Request Indexing**

Pages typically appear in Google Search results within **1–7 days**.

## Step 5: Monitor

Check these reports regularly after initial setup:

| Report | What to look for |
|---|---|
| **Coverage** | Crawl errors, excluded pages, indexing issues |
| **Core Web Vitals** | LCP, FID/INP, CLS thresholds |
| **Mobile Usability** | Tap target sizes, viewport configuration |

## Additional SEO Recommendations

- **Bing Webmaster Tools** — Submit the site at [bing.com/webmasters](https://www.bing.com/webmasters) for Bing/DuckDuckGo coverage
- **PageSpeed Insights** — Run a check at [pagespeed.web.dev](https://pagespeed.web.dev/) to catch performance issues
- **OG Tag Validation** — Test Open Graph tags at [opengraph.xyz](https://www.opengraph.xyz/) to ensure link previews render correctly
