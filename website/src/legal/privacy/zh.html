本网站不设置 Cookie。在浏览器存储（localStorage/sessionStorage）中，我们只保存你所使用功能所需的内容：你选择的语言、本会话中是否已完成自动语言跳转，你是否已打开或关闭过联系提示（以免其再次出现），以及你是否暂停了网站动画。这些信息保留在你的设备上，不会发送到任何服务器；它们对你所请求的功能绝对必要（TDDDG 第 25 条第 2 款第 2 项）。唯一的例外：如果网站自动将你跳转到你的语言，它会最多保存 30 秒你来源的页面（例如搜索引擎），并将其一次性交给上文所述的统计服务；即使没有跳转，统计服务也会收到这一信息。随后该记录会立即删除。你可以随时在浏览器设置中删除它们。

错误监控（Sentry，欧盟）

如果本网站出现程序错误，你的浏览器会向 Sentry（Functional Software, Inc.，欧盟数据区域）发送一份错误报告，以便我们找到并修复该错误。报告包含错误消息及堆栈跟踪、页面地址、浏览器和操作系统，以及出错前页面的技术痕迹（例如已加载的地址、被点击的页面元素和控制台消息），但不包含任何表单输入。没有错误时，页面不会向 Sentry 发送任何内容。不进行性能测量，不进行会话录制（Session Replay），也不进行会话跟踪；为此不会在你的设备上存储或读取任何内容。Sentry 不存储 IP 地址。地址中包含个人链接的页面（例如新闻通讯确认页）不发送错误报告。错误数据保存 30 天。Sentry 作为我们的数据处理者，依据数据处理协议处理这些数据；向美国传输时，适用与应用崩溃报告相同的规定（见第 15 节）。法律依据是 GDPR 第 6 条第 1 款(f)项（确保网站无错误运行的合法利益）。

6. 核心原则

WhisPaste 以隐私优先为设计原则。除非你明确选择云端服务进行转写或用于智能模式，否则你的音频和转写文本不会离开你的设备。默认情况下（退出制），应用会发送两条可单独关闭的数据流以推动开发：一是发送到我们运营的服务器的使用统计，二是通过 Sentry（欧盟数据区域）发送的崩溃报告。两者都绝不包含你的音频、转写文本、录音记录或你的姓名。崩溃报告仅在发生崩溃、应用无响应达 5 秒或以上以及严重错误时发送。详情见第 15 节。

7. 音频录制与转写

当你启动录音（通过快捷键或按钮）时，WhisPaste 会通过麦克风录制音频。根据设置，录音会以以下两种方式之一处理:

  • 本地/离线转写: 音频完全在你的设备上处理，使用本地 AI 模型：Whisper（通过 whisper.cpp）或 Parakeet（通过 sherpa-onnx 或 whisper.cpp 后端），取决于你的设置。没有任何音频离开你的电脑。
  • 云端转写（OpenAI 或 Deepgram）: 音频会被发送到你所选提供商的服务器进行转写。这需要你提供该提供商自己的 API 密钥。传输直接从你的设备发送给提供商；WhisPaste 不会通过我们自己的任何中间服务器转发、存储或处理这些录音。

智能模式（可选的文本整理）: 默认关闭。在本地运行时，转写文本由你设备上下载的语言模型处理。如果你在智能模式设置中选择 OpenAI 作为服务，转写文本连同所选预设的指令，会使用你自己的 OpenAI API 密钥直接发送给 OpenAI。

使用云端提供商时，适用其数据处理条款：OpenAI Privacy Policy 或 Deepgram Privacy Policy。

8. 录音

转写文本以 SQLite 数据库的形式存储在你设备的本地（Windows 下为 %APPDATA%\WhisPaste\，macOS 下为 ~/Library/Application Support/WhisPaste，Linux 下为 ~/.config/whispaste）。这些数据不会离开你的设备。对于每条记录，WhisPaste 还会在已知时保存文本粘贴到的应用的标识符。WhisPaste 向操作系统查询该应用的名称和图标，并将其缓存在同一应用文件夹中（app_icons）。这些同样只保留在你的设备上；当没有任何记录（包括回收站中的记录）再提及某个应用时，其名称和图标会被删除，删除录音时则全部删除。你可以随时在应用中查看、搜索、导出和删除录音。

笔记和笔记图片: WhisPaste 还会将你的笔记连同其版本历史存储在你的设备本地（每条笔记最多 50 个版本；存储预算为 4 MiB，但最新的 20 个版本即使超出预算也会保留，每条笔记最多 16 MiB；较旧的版本随后会被自动删除）。你添加到笔记中的图片（通过文件选择、从剪贴板粘贴或拖放）由 WhisPaste 保存在应用文件夹中；每条笔记最多可包含 20 张图片、32 MiB，全部笔记总计 512 MiB。保存前，WhisPaste 会删除图片中的附加信息，包括 GPS 位置、EXIF、XMP、IPTC 和注释信息；图片方向会保留。笔记和图片不会离开你的设备。

录音的 PIN 也会保护你的笔记：应用锁定期间，笔记和搜索不显示任何内容；你仍可记录快速笔记，但现有内容不会显示。如果你忘记了 PIN 并将其重置，所有录音、所有带版本历史的笔记以及所有笔记图片都会立即且不可恢复地被删除。设置、文本片段和替换规则会保留。

纠正观察记录：当你纠正转录文本时，WhisPaste 会在同一数据库中本地保存该纠正的原词和目标词、出现次数、你的决定（已接受或已拒绝）以及时间。统计采用 30 天的窗口；超过 30 天的观察记录会在启动时自动删除。这些数据绝不会被发送。你可以随时在纠正历史中逐条删除；恢复出厂设置会将其全部删除。

9. API 密钥的存储

云端提供商（OpenAI、Deepgram）的 API 密钥不会以明文形式保存在配置文件中，而是存放在你的操作系统的安全凭据存储中：Windows 凭据管理器、macOS 钥匙串，或 Linux 上的 libsecret。只有当你发出转写或智能模式请求时，密钥才会仅直接发送到该提供商的 API 端点。WhisPaste 不会将你的 API 密钥发送给任何其他服务或服务器。

10. 配置与本地存储

所有其他应用设置（语言、快捷键、主题、模型偏好等）都存储在与录音相同的应用文件夹中（见第 8 节）。设置本身从不传输。唯一的例外是：使用统计只上报被更改设置的名称，从不上报其值（见第 15 节）。

剪贴板: 应用仅在你的设备上读取剪贴板，用于粘贴听写内容并随后恢复之前的内容，以及用于仅保存在内存中的剪贴板历史。剪贴板内容从不写入磁盘，也从不传输。WhisPaste 不会将听写或剪贴板内容写入日志。若错误信息可能包含此类内容，则只记录错误类型；每一行日志还会额外去除路径和机密信息。

11. AI 模型下载

对于本地/离线转写，WhisPaste 从 Hugging Face 下载 AI 模型：Whisper 和 Parakeet 模型以及可选的智能模式语言模型均来自那里各自独立的仓库。损坏的 Whisper 模型会自动重新下载。下载时会向 Hugging Face 的服务器发出一个标准 HTTPS 请求。不会发送任何个人数据或标识符，只请求模型文件的 URL。已下载的模型存储在你设备的本地。仅当你在设置中请求时，才会从 GitHub 以发布文件的形式下载可选的、用于 NVIDIA 显卡加速的 CUDA 包。这同样只是标准 HTTPS 请求，不含标识符。

你可以选择在“设置 → 模型”中通过“+”在 Hugging Face 上搜索更多模型。此搜索默认关闭：只有在你于对话框中明确同意一次之后，应用才会把你的搜索词和筛选条件发送到 Hugging Face 的公开模型接口（huggingface.co/api/models，Hugging Face Inc.，美国）。为了显示所找到模型的大小和文件（在结果列表和模型详情视图中），应用还会从那里获取这些模型的文件列表（huggingface.co/api/models/<模型>/revision/main）。为此只会发送 Hugging Face 自己作为结果返回的模型名称。Hugging Face 会收到你的 IP 地址；不会发送录音、文本、账户数据、Cookie 或令牌，WhisPaste 也不会保存或统计你的搜索。法律依据是你的同意（GDPR 第 6 条第 1 款 a 项）；你可以随时在“设置 → 隐私”中撤回。

12. 自动更新

首次启动时，在你作出隐私选择之前，应用不会自动建立网络连接。你主动开始的模型下载除外。自动更新检查默认开启，但也只会在你作出该选择后开始。

更新机制取决于你的安装方式:

  • 通过 Microsoft Store、Mac App Store、Homebrew 或 Scoop 安装时，更新检查由相应的商店或包管理器负责；应用本身不进行单独的更新检查。（Snap 和 Flatpak 已在计划中，但目前尚不可用。）
  • 通过 Windows 安装程序（包括便携版）或直接从 GitHub 下载的 macOS DMG（Mac App Store 之外）安装时，应用会在启动时以及此后每 24 小时，通过从 GitHub 获取的已签名 appcast 源检查是否有新版本。
  • 在 Linux（AppImage/.deb）上，检查直接通过 GitHub Releases API 进行。

这些请求不包含个人数据；它们只是获取最新发布版本的版本信息。不会传输用户标识符、设备信息或使用数据。自动检查可在设置 → 更新中关闭。

在检查更新的同时，应用还会从 GitHub（我们公开仓库的一个固定发布版本）获取一个已签名的语音和文本模型目录文件。该文件只描述经过审核的模型（名称、大小、校验和、公开下载地址），不包含任何模型文件，并且只有在其签名与应用内置密钥相符时才会被使用。如果文件没有变化，条件请求（ETag）可避免重复下载。除请求本身外不发送任何内容。应用仍然只会在你开始下载时才下载模型。此获取遵循设置 → 更新中的同一开关；通过应用商店或软件包管理器安装时不会进行。

13. 向第三方的数据共享

WhisPaste 不会向第三方共享你的内容。只有当你明确选择时（用于转写的 OpenAI 或 Deepgram，用于智能模式的 OpenAI），音频或文本才会发送给云端提供商，并且是直接从你的设备发送，且遵循该提供商的条款。使用统计发送到我们自己运营的 Matomo 服务器（而非第三方）。崩溃报告由 Sentry（欧盟数据区域）作为数据处理者，依据数据处理协议进行处理（见第 15 节）。两者均可关闭，见第 15 节。

14. 网络连接

WhisPaste 仅出于以下目的建立网络连接:

  • OpenAI / Deepgram API — 启用云端转写时（由你触发）
  • OpenAI API — 仅当你选择 OpenAI 作为智能模式服务时（由你触发）
  • 你自己的兼容 OpenAI 的服务器（例如 LM Studio、Ollama 或你选择的提供商）— 仅当你为语音识别或智能模式输入该地址时（由你触发）。设备本地或局域网中的地址会留在本地；其他任何地址都会收到数据
  • Hugging Face — 下载本地 AI 模型时（由你触发），以及在 Hugging Face 搜索时（仅在你同意后）
  • GitHub — 下载可选的 CUDA 包时（由你触发）
  • GitHub — 用于自动更新检查（Releases API 或 appcast；默认开启，可关闭）
  • GitHub — 已签名的模型目录文件（仅包含模型信息，不含模型文件；与更新检查一起进行，可关闭）
  • Matomo — 使用统计（默认开启，可关闭，见第 15 节）
  • Sentry — 崩溃报告（默认开启，可关闭，见第 15 节）
  • api.whispaste.de (netcup) — 仅当你提交可选的反馈表单或撤回引用批准时（见第 16 节）
  • 我们的接口 api.whispaste.de — 为概览和支持页面中的“Get involved”区块获取项目数据，每天最多一次，且仅在其中一个页面打开时（见第 23 节）；订阅新闻通讯，仅当你提交时；以及在应用内提交的订阅等待你确认期间，查询它是否已被确认（见第 24 节）
  • MET Norway（api.met.no）和 OpenStreetMap 地点搜索（nominatim.openstreetmap.org）— 仅当你在概览中打开“Weather”卡片时：搜索地点时进行地点搜索，概览打开期间最多约每小时获取一次天气预报（默认关闭，见第 25 节）
  • 你为概览中“News”区块选择的 RSS 或 Atom 订阅源 — 仅在区块可见且窗口处于活动状态时，每个订阅源最多每小时一次（默认关闭，见第 26 节）

与互联网服务的连接使用 HTTPS 加密。你自己在设备上或局域网中的服务器可能使用未加密的 HTTP；在这种情况下，应用会显示警告。除更新检查、第 15 节所述的使用统计和崩溃报告第 23 节所述的项目数据获取以及第 25 节所述的天气预报外，不会发生后台网络活动。所有连接的完整技术清单见文件 NETWORK.md。

15. 假名使用统计与崩溃报告

为推动开发，WhisPaste 收集两条相互独立的数据流。两者默认均开启（退出制）——首次设置中的隐私步骤也对此作出说明。两者均不使用 Cookie，绝不包含音频、文本、录音记录或剪贴板内容，并且都可以在设置 → 隐私中分别关闭。那里的开关名称为 “帮助改进 WhisPaste”（使用统计）和 “发送崩溃报告”（崩溃报告）。

使用统计（Matomo）。 应用使用与网站相同的、位于欧盟的自托管 Matomo 服务器（第 4 节），但位于独立的测量区域。传输的是汇总的事件计数和固定类别：应用版本、操作系统、所选语音识别提供商、安装渠道、界面语言、更新渠道、更新检查结果、不含内容的设置步骤，以及被更改设置的名称（从不包含其值）。统计开启时，还会加入以下内容：所选语音模型的固定名称（small、medium、large-v3-turbo、Parakeet 或 cloud）、粗略的硬件类别（内存档位、GPU 厂商、Mac 芯片系列、计算后端）、粗略的速度类别、模型下载的成功或失败及错误类别、你是否采用了推荐的模型选择，以及自设置以来的时间（粗略分档）。对于语音模型，还会加入关于其使用情况和运行效果的事件：模型被安装、移除或选用，下载、检查或加载失败（附错误类别和下载源编号，从不包含其地址），回退到经过检查的模型；以及按听写汇总的成功或失败、速度等级、很快重新听写或粘贴后立即撤销，每项都附设备等级（内存档位、是否有 GPU、在 GPU 还是 CPU 上运行）。你在自动粘贴后是否立即在另一个应用中按下 Ctrl+Z 或 Cmd+Z，应用只会在之后的 15 秒内识别，而且只记为“是”或“否”；在 Mac 上使用你已授予的辅助功能权限，在 Wayland 下则记为未知。你按了哪些键从不保存也不传输。你自己的模型只以 Hugging Face 仓库和文件名（或服务器和文件名）以及运行时、系列、大小等级和 SHA-256 校验和出现；从你电脑导入的文件只以运行时、系列、大小等级和校验和出现。绝不传输：地址中文件名之后的部分（例如访问密钥）、登录凭据、本地路径或你设备上的文件名。带截断 IP 地址的原始数据在 180 天后删除；不含个人关联的汇总报告予以保留。

设置时的信息。 此外，在设置时你可以选择性地说明你用于什么听写（固定类别，如写作、开发或教育），以及你是如何得知 WhisPaste 的。仅发送你所选内容的固定标识符。你是否修改了名字，以状态形式上报（未修改、已修改、已清除），从不上报名字本身。这里没有单独的开关：这些信息随使用统计的开关运行，且仅在其开启时发送。

两条数据流的法律依据均为 GDPR 第 6 条第 1 款(f)项。我们的合法利益是应用的稳定性和持续改进。我们已进行权衡：仅收集汇总计数、固定类别以及不含内容的错误数据；保存期限较短；每条数据流都可随时关闭。因此，根据我们的评估，你的利益不会超过这一利益。

崩溃报告（Sentry，欧盟数据区域）。 仅发送崩溃、应用无响应达 5 秒或以上以及严重错误。不进行性能测量，也不进行会话跟踪。内容包括：错误消息和堆栈跟踪、应用版本、操作系统和 CPU 架构、安装渠道、应用最近的日志行（WhisPaste 不会将听写或剪贴板内容写入日志，见第 10 节），以及一个 12 个字符的假名化随机设备标识符。该标识符在首次启动时生成，不由计算机推导得出，删除其文件即可重置。Sentry 不存储 IP 地址，且应用默认不发送任何其他个人数据。发送前，应用会将本地文件路径中的用户名替换为占位符。包含 API 密钥等机密的事件会被丢弃；屏幕截图和屏幕内容从不发送。同一错误最多上报三次，一个会话总计最多发送 30 份报告。错误数据保存 30 天。Sentry 依据数据处理协议（DPA）作为数据处理者处理这些数据。为保障向美国（母公司所在地）的传输，适用 GDPR 第 46 条第 2 款(c)项规定的标准合同条款（SCC），或 EU-U.S. Data Privacy Framework，与第 3 节中 GitHub 的做法相同。关闭崩溃报告后，Sentry 会立即停止，包括崩溃和无响应报告，并且在之后的启动中根本不会启动。

设备上的假名标识符。 用于崩溃报告的安装标识符以及每周数值的盐值存储在本地。这对于已开启的功能在技术上是必需的（TDDDG 第 25 条第 2 款第 2 项），因此无需单独同意。对于按周分析，会发送一个本地生成的标记：由从不传输的随机设备值与日历周计算出的哈希值。它每周变化，不是持久标识符；使用统计关闭时，既不生成也不发送。此外，每次应用启动都会生成一个随机访客 ID，该 ID 从不保存，仅用于关联同一次程序运行中的事件。

两条数据流中绝不传输：你的音频、转写文本、剪贴板内容、录音记录、文本片段、标签、笔记、API 密钥或你的姓名。使用统计还不包含具体的快捷键、文件路径、光标位置或目标应用。

反对权。 你可以随时反对任一数据流（GDPR 第 21 条），方法是在设置 → 隐私中将其关闭。使用统计关闭后，设置时的可选信息也不会发送。

16. 反馈表单

WhisPaste 在应用中提供一个可选的、自愿填写的反馈表单。提交时，你的评分、反馈文本、所选类别、应用版本、经哈希处理且无法直接识别你的设备标识符，以及应用界面语言，会被发送到我们自己的接口 api.whispaste.de，并存储在位于德国的 netcup GmbH 服务器上的 MySQL 数据库中（见第 17 节）。只有当你选择填写时，才会另外发送联系邮箱地址和首选联系语言，以便我们回复你的反馈。法律依据: GDPR 第 6 条第 1 款(a)项（通过主动提交表单给予的同意）。除非你提交表单，否则不会传输上述任何数据。

截至 2026 年 11 月 5 日，我们将此前收到的条目一次性复制到了我们自己的接口 api.whispaste.de（位于德国的 netcup GmbH 服务器，见第 17 节），如果你提供了联系邮箱和联系语言，也一并复制。我们按现状使用这份副本，也用于本网站上的引用。在那里，每日清理会在 90 天后删除未获批准和已撤回的条目；已批准的引用会保留，但 90 天后会失去联系信息。期限始终从最初的接收日期起算。来自应用的新反馈和撤回会直接发送到 api.whispaste.de。旧版应用仍会发送到我们之前的 Supabase 数据库，待其不再使用后我们会将其关闭。对于 2026 年 11 月 5 日副本中的条目，我们始终会遵从撤回引用批准的决定（GDPR 第 7 条第 3 款）：无论你在应用中还是通过电子邮件声明撤回，我们都会在收到后立即、最迟在一个月内（GDPR 第 12 条第 3 款）手动同步到副本中；这不会自动发生。

之前的 Supabase 数据库（旧版应用）：旧版应用仍会将反馈和撤回发送到我们之前在 Supabase 的数据库（Supabase Inc.，依据 GDPR 第 28 条作为我们的数据处理者），数据存放在法兰克福（德国，欧盟）的数据中心。它接收与上文相同的信息（评分、反馈文本、类别、应用版本、经哈希处理的设备标识、应用语言，自愿提供的联系邮箱和联系语言，以及在你同意引用时的同意证明和撤回码的哈希值），另外还有服务器生成的你的 IP 地址的 SHA-256 哈希值，它仅用于限制每个发送者的提交次数（防止滥用，GDPR 第 6 条第 1 款(f)项）。每日清理会在接收 30 天后清空 IP 哈希值和设备标识，在 90 天后删除未获批准和已撤回的条目，并在 90 天后移除已批准引用中的联系信息。该数据库不含备份副本。当旧版本几乎不再使用时，我们会将其关闭，最迟在首个直接发送到 api.whispaste.de 的应用版本发布三个月后。关于托管服务商的备份，见第 17 节。

此外，你可以在表单中明确勾选一个选项，允许你的反馈文本以匿名引语的形式显示在本网站上。该选项仅在你选择“表扬”类型时出现，因为引语的写法与评分相似：说明你喜欢什么，以及仍有哪些可改进之处。错误报告和功能建议永远不会作为引语发布。该选项默认未勾选。勾选后，只显示你的文本和评分，绝不显示你的姓名或邮箱地址，并且仅在我们经过编辑审核后才会显示。法律依据: GDPR 第 6 条第 1 款(a)项。作为同意的证明，我们会保存同意的时间（由我们的服务器设定）以及你所见同意文本的版本。

在应用中撤回: 你同意后，应用会生成一个随机的撤回码，该码仅保存在你的设备上，存放在操作系统的凭据存储中（钥匙串、Windows 凭据管理器，或 Linux 上的 Secret Service；若均不可用，则存放在应用设置中）。我们只接收该码的哈希值（SHA-256），无法由此还原出该码；仅凭哈希值也无法撤回同意。我们会将其与你的反馈记录一同保存，最长保存至你的撤回请求送达我们为止。若没有撤回，我们会随记录一同删除它：90 天后，或者若我们已将你的反馈批准为引语，则在删除该记录时删除。在反馈区域点击“撤回同意”，即可一键撤回你从这台设备上给出的所有同意。在设备上，撤回立即生效。只要 WhisPaste 在联网状态下运行，撤回就会发送给我们：点击时立即发送、下次启动应用时发送、打开反馈区域时发送，并且在应用运行期间，以最长一小时的递增间隔重复发送，总计最长 30 天。在我们的服务器确认收到之前，应用将撤回显示为“正在发送”，之后显示为“撤回已传达”。如果无法送达（例如我们的服务器因无效而拒绝，或 30 天后仍未成功），应用会告知你，并提示你通过邮件撤回。我们的服务器一旦收到撤回，就会撤销你的同意及引语的批准，删除哈希值，并记录撤回的时间。同意和撤回的时间在删除前作为证明保存。我们的每日清理会在你的反馈送达后最迟 90 天删除该反馈记录，并且无论如何，最迟在撤回送达后 90 天删除。如果撤回送达时你的反馈已超过 90 天，则下一次每日清理会将其删除，因此可能远早于撤回后 90 天。对于服务器上的这些期限，以我们服务器在每次收到时的时间为准。引语作为参考，会在约 24 小时内随网站的下一次每日更新从网站上消失；如果更新失败，可能需要更长时间。

通过邮件撤回: 如果你是在另一台设备上给出的同意、重新安装了应用、因其他原因此设备上没有保存撤回码，或应用无法送达撤回请求，请通过邮件发送至 kontakt@whispaste.de 撤回。应用会为此提供一封预先填好内容的邮件。如果应用知道你最近一次反馈的日期，会自动填入；对于每一个未送达的撤回，应用还会填入上述哈希值作为撤回参考，但从不填入撤回码本身。这使我们能够找到记录并手动撤销批准；之后适用与应用内撤回相同的删除期限。我们会保留你的撤回邮件，作为我们已执行撤回的证明，并且最迟在邮件到达后 90 天从我们的邮箱中删除，与反馈记录的期限相同（存储限制，GDPR 第 5 条第 1 款(e)项）。你通过自己的邮件程序和邮件服务商将邮件发送给 WhisPaste 的运营者。其传输不是端到端加密的；我们无法影响你的服务商所选的传输路径。撤回参考是一个哈希值，无法由此还原出撤回码。除该撤回参考外，邮件仅包含你最近一次反馈的日期（如果应用知道的话）。如果应用找不到邮件程序，它会显示该地址，并提供复制地址和消息的选项。未送达的撤回及其撤回码，会在你确认已发送邮件后从你的设备上删除，并且最迟在你撤回后 90 天删除。设备上的这一期限，从你在设备上点击“撤回同意”的时刻起计算，依据的是你设备的时钟，而不是邮件到达我们的时间。为了使应用即使在凭据存储不可读时仍能向你提供撤回参考，它会在其设置中保存你同意的哈希值以及撤回的状态，但从不保存撤回码。这些信息仅保留在你的设备上，不包含在任何设置导出中。对于同意，只要同意有效，这些信息就会保留。撤回后，应用会在我们的服务器确认撤回或你确认已发送邮件后将其删除，并且最迟在你撤回后 90 天删除，即使撤回未能送达。撤回不影响撤回之前已进行的发布的合法性（GDPR 第 7 条第 3 款）。

数据通过 TLS 加密发送至我们的接口 api.whispaste.de。该接口运行在 netcup GmbH（Daimlerstraße 25, 76185 Karlsruhe, Germany）的服务器上，netcup 依据 GDPR 第 28 条作为我们的数据处理者行事；处理在德国进行。接口会将你的消息以电子邮件形式转发到我们的邮箱，且自身不存储其内容。一旦你的咨询得到解决，我们就会删除该邮件，最迟在 12 个月后删除，除非法定保存义务另有要求。已删除的数据最多可能在我们的托管服务商 netcup（德国）的每日备份中再保留 7 天，之后会被自动覆盖；我们自己不做备份。

滥用防护: 为防止表单被用于垃圾信息，我们会限制每个发件人的消息数量。为此，我们从不以明文存储你的 IP 地址和电子邮箱地址，而仅以使用密钥生成的哈希值存储，并且仅保留到相应时间窗口结束为止（最多 24 小时，之后条目会自动删除）。一个隐藏的检查字段以及填写表单所用的时间，有助于识别自动化提交；为此不会收集其他数据。接口的技术日志不包含 IP 地址、电子邮箱地址或消息内容，只记录请求的类型和结果，并在 14 天后删除。法律依据为 GDPR 第 6 条第 1 款(f)项（防范滥用）。

除非你提交，否则不会传输任何表单数据。你可以随时反对此处理（GDPR 第 21 条），并要求我们删除你的消息；请写信至版权声明（Impressum）中列出的地址。“前往创意板”按钮会链接到我们在 VotePit（app.votepit.com）上的创意板，这是一项独立运营的服务，有其自己的隐私政策；只有当你打开该链接时，数据才会流向那里。

23. 应用概览中的项目数据

应用概览中的 “Get involved” 区块显示 WhisPaste 在 GitHub 上的星标数和 YouTube 频道的订阅人数（应用没有中文界面，因此这里引用英文标签）。应用从我们自己的接口 api.whispaste.de（netcup GmbH，德国，见第 17 节）获取这些数字，从不直接访问 GitHub 或 YouTube。它每天最多请求一次，并且只在显示该区块的概览或支持页面打开时请求。如果你隐藏该区块（“Hide this section”或在“Customise overview”中），应用将不再获取这些数字，概览和支持页面都不会请求。

请求中不包含任何标识符、账户、设置或应用中的内容。出于技术原因，服务器会收到你的 IP 地址以便返回响应。该地址会记录在 Web 服务器的访问日志中，日志最迟 14 天后删除。为限制每个发送方的请求次数，接口只使用以密钥生成的 IP 地址哈希值，该值一分钟后失效。响应只包含这两个数字，最多可缓存一小时。接口本身最多每 3 小时向 GitHub 和 YouTube（Google）查询一次，不会传递任何关于你的数据。法律依据: GDPR 第 6 条第 1 款(f)项（展示最新项目数据的正当利益）。

24. 新闻通讯

你可以在网站或应用中订阅 WhisPaste 新闻通讯。为此，我们会处理你的电子邮件地址，并先向你发送一封确认邮件（双重确认）。只有在 48 小时内确认邮件中的链接后，你才会加入列表。如果你没有确认，链接会过期，我们会在下一次清理时删除该订阅。不提交订阅就不会传输任何数据。

  • 目的: 关于更新的新闻、使用技巧以及 WhisPaste 的幕后信息。
  • 法律依据: 你的同意（GDPR 第 6 条第 1 款(a)项）。
  • 存储的数据: 你的电子邮件地址（加密存储）、所选语言、你在哪里订阅（网站或应用）、订阅和确认的时间、同意文本的版本，以及以密钥生成的、不可逆的 IP 地址哈希值。我们用这些数据证明你的同意。
  • 防止滥用: 为防止有人用确认邮件轰炸他人的地址，我们限制每个 IP 地址和每个电子邮件地址的订阅次数。一个不可见的检查字段和填写所用时间有助于识别自动订阅；为此不会存储其他数据。接口的技术日志既不包含电子邮件地址，也不包含 IP 地址，并在 14 天后删除。
  • 应用内确认: 如果你在应用中订阅，应用会生成一个随机状态码，并随订阅一起发送。我们只保存该状态码经密钥计算得出的不可逆哈希值。状态码本身保存在你设备上的应用设置中；它只能表明从这台设备提交的订阅是否已被确认，因此不保存在操作系统的凭据存储中。在订阅等待你确认期间（最长 48 小时），应用会用这个状态码向 api.whispaste.de 查询你是否已确认：在“Get involved”区块显示或应用窗口切换到前台时查询，最多每两分钟一次；当确认页面将你带回应用时立即查询。在此过程中，不会向我们发送你的电子邮件地址或任何其他信息。你确认后，我们的服务器只报告一次确认结果，并删除该哈希值；应用会删除状态码，只保留确认时间。如果未确认，双方都会在 48 小时后将其删除。法律依据是你的同意（GDPR 第 6 条第 1 款(a)项）。为防止查询被滥用，我们限制每个状态码和每个 IP 地址的查询次数；为此，我们只以经密钥计算的哈希值形式保存两者，且仅保存到当前一小时时间窗口结束（GDPR 第 6 条第 1 款(f)项，防止滥用）。
  • 欢迎邮件: 您确认之后，我们会向您发送一封欢迎邮件，内含首批使用步骤和一条小贴士，仅发送一次。它基于同一份同意，不含追踪像素，也不会产生任何额外存储。
  • 已订阅: 如果您在应用中用已确认的地址再次订阅，我们会向您发送邮件《您已订阅 WhisPaste 资讯》。为了限制发给您的邮件数量，我们为此最多保存 48 小时：应用设备密钥的不可逆哈希值、此类最近一封邮件的时间和计数，以及当前 30 天周期的起点。只有当您点击该邮件中的“关联应用”时，应用才会得知您的地址已订阅。
  • 来自应用的语言: 如果您在应用中订阅，或通过“关联应用”将其与您的订阅关联，我们会在订阅结束前保存应用设备密钥的不可逆哈希值。它仅用于在您于应用中切换语言时，将应用的语言沿用到您的邮件订阅中；应用为此无需您的地址。一旦您退订、您的地址无法送达或订阅结束，该值即被删除。如果您以另一种语言再次订阅，我们此后将用该语言给您写信。
  • 不做追踪: 我们不统计你是否打开邮件或点击链接。邮件中不含追踪像素、追踪参数或远程加载的图片。
  • 发送: 通过我们在德国 netcup GmbH 的自有邮件服务器发送（GDPR 第 28 条规定的处理者）。我们不会将数据转交给第三方。
  • 撤回与退订: 你可以随时通过每封邮件中的退订链接撤回同意。之后我们会删除你的地址和语言。为确保不再给你发送邮件，只会在屏蔽列表中保留一个由地址生成的不可逆值。我们会将你的同意证明（时间、同意文本版本、订阅位置）保存三年，然后连同屏蔽列表条目一起自动删除。撤回同意不影响此前发送的合法性（GDPR 第 7 条第 3 款）。关于托管服务商的备份，见第 17 节。

25. 应用概览中的天气

应用概览中的“Weather”卡片默认关闭（应用没有中文版本，因此我们引用英文标签）。你可以在“Customise overview”中打开它，然后自己选择一个地点。WhisPaste 不会为此使用设备的定位服务。

地点搜索：当你搜索地点时，应用会把你的搜索词和应用语言发送到 OpenStreetMap Foundation 的 Nominatim 地点搜索（英国，适用欧盟委员会的充分性认定）。只有在你点击“Search”或按回车键时才会搜索，输入过程中从不搜索，且每秒最多一次。参见 OpenStreetMap Foundation 隐私政策。地点数据 © OpenStreetMap 贡献者（ODbL）。

天气预报：为获取天气预报，应用会把所选地点的坐标（四舍五入到小数点后两位，约一公里）直接发送到挪威气象研究所（MET Norway，挪威奥斯陆，位于欧洲经济区内）的天气接口。它最多约每小时请求一次，仅在上次的预报过期后、且仅在概览可见时请求；在后台或未选择地点时从不请求。离线时，卡片保持安静并显示上次的预报。

两种请求都不包含标识符、账户或应用中的任何内容，只包含应用名称和版本以及我们网站的地址作为联系方式，这是两个服务的要求。出于技术原因，两个服务都会收到你的 IP 地址。所选地点（名称和四舍五入后的坐标）和上次的预报只保存在你设备上的应用设置中；“Remove place”会删除这两者。天气数据来自 MET Norway，采用 CC BY 4.0 许可。法律依据是 GDPR 第 6 条第 1 款 (f) 项（为提供你所开启的天气显示的正当利益）。

26. 应用概览中的新闻

应用概览中的“News”区块默认关闭（应用没有中文版本，因此我们引用英文标签）。你可以在“Customise overview”中打开它，并在“Sources”中自己决定显示哪些 RSS 或 Atom 订阅源，最多五个。我们会推荐自己博客的订阅源（whispaste.de/blog/feed.xml，见第 3 节）；其他任何地址都由你自己输入。

获取：应用直接从各订阅源的服务器加载你选择的订阅源：添加时加载一次，之后最多每小时一次，并且仅在概览显示该区块且应用窗口处于活动状态时进行。应用在启动时、后台或没有订阅源时从不请求。请求只是以“WhisPaste”作为程序名称获取订阅源地址，不含设备标识、不含 Cookie，也不含应用中的任何内容。出于技术原因，订阅源服务器会收到你的 IP 地址；对此适用其运营方的隐私政策。如果你输入以 http:// 开头的地址，获取过程不加密。

你的订阅源列表和最近加载的条目（标题、来源、日期、链接）只保存在你设备上的应用数据库中。删除某个订阅源时，应用也会删除它的条目。点击条目会在浏览器中打开它。法律依据为 GDPR 第 6 条第 1 款 f 项（提供你已开启的新闻的正当利益）。
