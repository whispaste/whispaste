4. 无 Cookie 网页分析（Matomo）

本网站使用无 Cookie的网页分析软件 Matomo（端点: matomo.silvio-und-maik.de），以生成汇总的使用统计。不会设置 Cookie，也不会在你的设备上存储或读取任何信息；由于跟踪被强制为无 Cookie 方式且 IP 地址已被截断，依据 TDDDG 第 25 条，既无需同意，也无需 Cookie 横幅。收集的内容包括（但不限于）截断为两个字节的 IP 地址（最后两个字节被置零）、浏览器和设备类型、屏幕分辨率、语言、来源地区、来源页以及访问的子页面，以及匿名的技术性能指标（Core Web Vitals：加载时间、布局稳定性、响应时间）。不进行画像分析，不进行跨设备跟踪，也不向第三方共享；这些数据无法与具体个人关联。位置推断（国家和地区）在请求到达时仍基于完整地址进行；仅存储截断后的地址。原始数据在 180 天后删除，不含个人关联的汇总报告予以保留。应用的使用统计在同一服务器上运行（见第 15 节），但位于独立的测量区域。本网站不加载外部字体或 CDN 服务；其他所有资源均由 GitHub Pages 在本地提供。法律依据: GDPR 第 6 条第 1 款(f)项（按需改进的合法利益）。你可以随时反对此处理（GDPR 第 21 条）。请在下方的字段中启用退出选项。

本网站不设置 Cookie。在浏览器存储（localStorage/sessionStorage）中，我们只保存你所使用功能所需的内容：你选择的语言、本会话中是否已完成自动语言跳转，以及你是否已打开或关闭过联系提示（以免其再次出现）。这些信息保留在你的设备上，不会发送到任何服务器；它们对你所请求的功能绝对必要（TDDDG 第 25 条第 2 款第 2 项）。你可以随时在浏览器设置中删除它们。

6. 核心原则

WhisPaste 以隐私优先为设计原则。除非你明确选择云端服务进行转写或用于智能模式，否则你的音频和转写文本不会离开你的设备。默认情况下（退出制），应用会发送两条可单独关闭的数据流以推动开发：一是发送到我们运营的服务器的使用统计，二是通过 Sentry（欧盟数据区域）发送的崩溃报告。两者都绝不包含你的音频、转写文本、历史记录或你的姓名。崩溃报告仅在发生崩溃、应用无响应达 5 秒或以上以及严重错误时发送。详情见第 15 节。

7. 音频录制与转写

当你启动录音（通过快捷键或按钮）时，WhisPaste 会通过麦克风录制音频。根据设置，录音会以以下两种方式之一处理:

  • 本地/离线转写: 音频完全在你的设备上处理，使用本地 AI 模型：Whisper（通过 whisper.cpp）或 Parakeet（通过 sherpa-onnx 或 whisper.cpp 后端），取决于你的设置。没有任何音频离开你的电脑。
  • 云端转写（OpenAI 或 Deepgram）: 音频会被发送到你所选提供商的服务器进行转写。这需要你提供该提供商自己的 API 密钥。传输直接从你的设备发送给提供商；WhisPaste 不会通过我们自己的任何中间服务器转发、存储或处理这些录音。

智能模式（可选的文本整理）: 默认关闭。在本地运行时，转写文本由你设备上下载的语言模型处理。如果你在智能模式设置中选择 OpenAI 作为服务，转写文本连同所选预设的指令，会使用你自己的 OpenAI API 密钥直接发送给 OpenAI。

使用云端提供商时，适用其数据处理条款：OpenAI Privacy Policy 或 Deepgram Privacy Policy。

8. 转写历史

转写文本以 SQLite 数据库的形式存储在你设备的本地（Windows 下为 %APPDATA%\WhisPaste\，macOS 下为 ~/Library/Application Support/WhisPaste，Linux 下为 ~/.config/whispaste）。这些数据不会离开你的设备。你可以随时在应用中查看、搜索、导出和删除转写历史。

笔记和笔记图片: WhisPaste 还会将你的笔记连同其版本历史存储在你的设备本地（每条笔记最多 50 个版本，总计 4 MiB；较旧的版本随后会被自动删除）。你添加到笔记中的图片（通过文件选择、从剪贴板粘贴或拖放）由 WhisPaste 保存在应用文件夹中；每条笔记最多可包含 20 张图片、32 MiB，全部笔记总计 512 MiB。保存前，WhisPaste 会删除图片中的附加信息，包括 GPS 位置、EXIF、XMP、IPTC 和注释信息；图片方向会保留。笔记和图片不会离开你的设备。

历史记录的 PIN 也会保护你的笔记：应用锁定期间，笔记和搜索不显示任何内容；你仍可记录快速笔记，但现有内容不会显示。如果你忘记了 PIN 并将其重置，所有录音、所有带版本历史的笔记以及所有笔记图片都会立即且不可恢复地被删除。设置、文本片段和替换规则会保留。

9. API 密钥的存储

云端提供商（OpenAI、Deepgram）的 API 密钥不会以明文形式保存在配置文件中，而是存放在你的操作系统的安全凭据存储中：Windows 凭据管理器、macOS 钥匙串，或 Linux 上的 libsecret。只有当你发出转写或智能模式请求时，密钥才会仅直接发送到该提供商的 API 端点。WhisPaste 不会将你的 API 密钥发送给任何其他服务或服务器。

10. 配置与本地存储

所有其他应用设置（语言、快捷键、主题、模型偏好等）都存储在与转写历史相同的应用文件夹中（见第 8 节）。设置本身从不传输。唯一的例外是：使用统计只上报被更改设置的名称，从不上报其值（见第 15 节）。

剪贴板: 应用仅在你的设备上读取剪贴板，用于粘贴听写内容并随后恢复之前的内容，以及用于仅保存在内存中的剪贴板历史。剪贴板内容从不写入磁盘，也从不传输。WhisPaste 不会将听写或剪贴板内容写入日志。若错误信息可能包含此类内容，则只记录错误类型；每一行日志还会额外去除路径和机密信息。

11. AI 模型下载

对于本地/离线转写，WhisPaste 从 Hugging Face 下载 AI 模型：Whisper 和 Parakeet 模型以及可选的智能模式语言模型均来自那里各自独立的仓库。损坏的 Whisper 模型会自动重新下载。下载时会向 Hugging Face 的服务器发出一个标准 HTTPS 请求。不会发送任何个人数据或标识符，只请求模型文件的 URL。已下载的模型存储在你设备的本地。

12. 自动更新

更新机制取决于你的安装方式:

  • 通过 Microsoft Store、Mac App Store、Homebrew 或 Scoop 安装时，更新检查由相应的商店或包管理器负责；应用本身不进行单独的更新检查。（Snap 和 Flatpak 已在计划中，但目前尚不可用。）
  • 通过 Windows 安装程序（包括便携版）或直接从 GitHub 下载的 macOS DMG（Mac App Store 之外）安装时，应用会在启动时以及此后每 24 小时，通过从 GitHub 获取的已签名 appcast 源检查是否有新版本。
  • 在 Linux（AppImage/.deb）上，检查直接通过 GitHub Releases API 进行。

这些请求不包含个人数据；它们只是获取最新发布版本的版本信息。不会传输用户标识符、设备信息或使用数据。自动检查可在设置 → 更新中关闭。

13. 向第三方的数据共享

WhisPaste 不会向第三方共享你的内容。只有当你明确选择时（用于转写的 OpenAI 或 Deepgram，用于智能模式的 OpenAI），音频或文本才会发送给云端提供商，并且是直接从你的设备发送，且遵循该提供商的条款。使用统计发送到我们自己运营的 Matomo 服务器（而非第三方）。崩溃报告由 Sentry（欧盟数据区域）作为数据处理者，依据数据处理协议进行处理（见第 15 节）。两者均可关闭，见第 15 节。

14. 网络连接

WhisPaste 仅出于以下目的建立网络连接:

  • OpenAI / Deepgram API — 启用云端转写时（由你触发）
  • OpenAI API — 仅当你选择 OpenAI 作为智能模式服务时（由你触发）
  • 你自己的兼容 OpenAI 的服务器（例如 LM Studio、Ollama 或你选择的提供商）— 仅当你为语音识别或智能模式输入该地址时（由你触发）。设备本地或局域网中的地址会留在本地；其他任何地址都会收到数据
  • Hugging Face — 下载本地 AI 模型时（由你触发）
  • GitHub — 用于自动更新检查（Releases API 或 appcast；默认开启，可关闭）
  • Matomo — 使用统计（默认开启，可关闭，见第 15 节）
  • Sentry — 崩溃报告（默认开启，可关闭，见第 15 节）
  • Supabase — 仅当你提交可选的反馈表单时（见第 16 节）

与互联网服务的连接使用 HTTPS 加密。你自己在设备上或局域网中的服务器可能使用未加密的 HTTP；在这种情况下，应用会显示警告。除更新检查以及第 15 节所述的使用统计和崩溃报告外，不会发生后台网络活动。所有连接的完整技术清单见文件 NETWORK.md。

15. 假名使用统计与崩溃报告

为推动开发，WhisPaste 收集两条相互独立的数据流。两者默认均开启（退出制）——首次设置中的隐私步骤也对此作出说明。两者均不使用 Cookie，绝不包含音频、文本、历史记录或剪贴板内容，并且都可以在设置 → 隐私中分别关闭。那里的开关名称为 “帮助改进 WhisPaste”（使用统计）和 “发送崩溃报告”（崩溃报告）。

使用统计（Matomo）。 应用使用与网站相同的、位于欧盟的自托管 Matomo 服务器（第 4 节），但位于独立的测量区域。传输的是汇总的事件计数和固定类别：应用版本、操作系统、所选语音识别提供商、安装渠道、界面语言、更新渠道、更新检查结果、不含内容的设置步骤，以及被更改设置的名称（从不包含其值）。统计开启时，还会加入以下内容：所选语音模型的固定名称（small、medium、large-v3-turbo、Parakeet 或 cloud）、粗略的硬件类别（内存档位、GPU 厂商、Mac 芯片系列、计算后端）、粗略的速度类别、模型下载的成功或失败及错误类别、你是否采用了推荐的模型选择，以及自设置以来的时间（粗略分档）。带截断 IP 地址的原始数据在 180 天后删除；不含个人关联的汇总报告予以保留。

设置时的信息。 此外，在设置时你可以选择性地说明你用于什么听写（固定类别，如写作、开发或教育），以及你是如何得知 WhisPaste 的。仅发送你所选内容的固定标识符。你是否修改了名字，以状态形式上报（未修改、已修改、已清除），从不上报名字本身。这里没有单独的开关：这些信息随使用统计的开关运行，且仅在其开启时发送。

两条数据流的法律依据均为 GDPR 第 6 条第 1 款(f)项。我们的合法利益是应用的稳定性和持续改进。我们已进行权衡：仅收集汇总计数、固定类别以及不含内容的错误数据；保存期限较短；每条数据流都可随时关闭。因此，根据我们的评估，你的利益不会超过这一利益。

崩溃报告（Sentry，欧盟数据区域）。 仅发送崩溃、应用无响应达 5 秒或以上以及严重错误。不进行性能测量，也不进行会话跟踪。内容包括：错误消息和堆栈跟踪、应用版本、操作系统和 CPU 架构、安装渠道、应用最近的日志行（WhisPaste 不会将听写或剪贴板内容写入日志，见第 10 节），以及一个 12 个字符的假名化随机设备标识符。该标识符在首次启动时生成，不由计算机推导得出，删除其文件即可重置。Sentry 不存储 IP 地址，且应用默认不发送任何其他个人数据。发送前，应用会将本地文件路径中的用户名替换为占位符。包含 API 密钥等机密的事件会被丢弃；屏幕截图和屏幕内容从不发送。同一错误最多上报三次，一个会话总计最多发送 30 份报告。错误数据保存 30 天。Sentry 依据数据处理协议（DPA）作为数据处理者处理这些数据。为保障向美国（母公司所在地）的传输，适用 GDPR 第 46 条第 2 款(c)项规定的标准合同条款（SCC），或 EU-U.S. Data Privacy Framework，与第 3 节中 GitHub 的做法相同。关闭崩溃报告后，Sentry 会立即停止，包括崩溃和无响应报告，并且在之后的启动中根本不会启动。

设备上的假名标识符。 用于崩溃报告的安装标识符以及每周数值的盐值存储在本地。这对于已开启的功能在技术上是必需的（TDDDG 第 25 条第 2 款第 2 项），因此无需单独同意。对于按周分析，会发送一个本地生成的标记：由从不传输的随机设备值与日历周计算出的哈希值。它每周变化，不是持久标识符；使用统计关闭时，既不生成也不发送。此外，每次应用启动都会生成一个随机访客 ID，该 ID 从不保存，仅用于关联同一次程序运行中的事件。

两条数据流中绝不传输：你的音频、转写文本、剪贴板内容、历史记录、文本片段、标签、笔记、API 密钥或你的姓名。使用统计还不包含具体的快捷键、文件路径、光标位置或目标应用。

反对权。 你可以随时反对任一数据流（GDPR 第 21 条），方法是在设置 → 隐私中将其关闭。使用统计关闭后，设置时的可选信息也不会发送。

16. 反馈表单

WhisPaste 在应用中提供一个可选的、自愿填写的反馈表单。提交时，你的评分、反馈文本、所选类别、应用版本、经哈希处理且无法直接识别你的设备标识符，以及应用界面语言，会被发送到我们运营的 Supabase 数据库。只有当你选择填写时，才会另外发送联系邮箱地址和首选联系语言，以便我们回复你的反馈。法律依据: GDPR 第 6 条第 1 款(a)项（通过主动提交表单给予的同意）。除非你提交表单，否则不会传输上述任何数据。

此外，你可以在表单中明确勾选一个选项，允许你的反馈文本以匿名引语的形式显示在本网站上。该选项仅在你选择“表扬”类型时出现，因为引语的写法与评分相似：说明你喜欢什么，以及仍有哪些可改进之处。错误报告和功能建议永远不会作为引语发布。该选项默认未勾选。勾选后，只显示你的文本和评分，绝不显示你的姓名或邮箱地址，并且仅在我们经过编辑审核后才会显示。法律依据: GDPR 第 6 条第 1 款(a)项。作为同意的证明，我们会保存同意的时间（由我们的服务器设定）以及你所见同意文本的版本。

在应用中撤回: 你同意后，应用会生成一个随机的撤回码，该码仅保存在你的设备上，存放在操作系统的凭据存储中（钥匙串、Windows 凭据管理器，或 Linux 上的 Secret Service；若均不可用，则存放在应用设置中）。我们只接收该码的哈希值（SHA-256），无法由此还原出该码；仅凭哈希值也无法撤回同意。我们会将其与你的反馈记录一同保存，最长保存至你的撤回请求送达我们为止。若没有撤回，我们会随记录一同删除它：90 天后，或者若我们已将你的反馈批准为引语，则在删除该记录时删除。在反馈区域点击“撤回同意”，即可一键撤回你从这台设备上给出的所有同意。在设备上，撤回立即生效。只要 WhisPaste 在联网状态下运行，撤回就会发送给我们：点击时立即发送、下次启动应用时发送、打开反馈区域时发送，并且在应用运行期间，以最长一小时的递增间隔重复发送，总计最长 30 天。在我们的服务器确认收到之前，应用将撤回显示为“正在发送”，之后显示为“撤回已传达”。如果无法送达（例如我们的服务器因无效而拒绝，或 30 天后仍未成功），应用会告知你，并提示你通过邮件撤回。我们的服务器一旦收到撤回，就会撤销你的同意及引语的批准，删除哈希值，并记录撤回的时间。同意和撤回的时间在删除前作为证明保存。我们的每日清理会在你的反馈送达后最迟 90 天删除该反馈记录，并且无论如何，最迟在撤回送达后 90 天删除。如果撤回送达时你的反馈已超过 90 天，则下一次每日清理会将其删除，因此可能远早于撤回后 90 天。对于服务器上的这些期限，以我们服务器在每次收到时的时间为准。引语作为参考，会在约 24 小时内随网站的下一次每日更新从网站上消失；如果更新失败，可能需要更长时间。

通过邮件撤回: 如果你是在另一台设备上给出的同意、重新安装了应用、因其他原因此设备上没有保存撤回码，或应用无法送达撤回请求，请通过邮件发送至 kontakt@whispaste.de 撤回。应用会为此提供一封预先填好内容的邮件。如果应用知道你最近一次反馈的日期，会自动填入；对于每一个未送达的撤回，应用还会填入上述哈希值作为撤回参考，但从不填入撤回码本身。这使我们能够找到记录并手动撤销批准；之后适用与应用内撤回相同的删除期限。我们会保留你的撤回邮件，作为我们已执行撤回的证明，并且最迟在邮件到达后 90 天从我们的邮箱中删除，与反馈记录的期限相同（存储限制，GDPR 第 5 条第 1 款(e)项）。你通过自己的邮件程序和邮件服务商将邮件发送给 WhisPaste 的运营者。其传输不是端到端加密的；我们无法影响你的服务商所选的传输路径。撤回参考是一个哈希值，无法由此还原出撤回码。除该撤回参考外，邮件仅包含你最近一次反馈的日期（如果应用知道的话）。如果应用找不到邮件程序，它会显示该地址，并提供复制地址和消息的选项。未送达的撤回及其撤回码，会在你确认已发送邮件后从你的设备上删除，并且最迟在你撤回后 90 天删除。设备上的这一期限，从你在设备上点击“撤回同意”的时刻起计算，依据的是你设备的时钟，而不是邮件到达我们的时间。为了使应用即使在凭据存储不可读时仍能向你提供撤回参考，它会在其设置中保存你同意的哈希值以及撤回的状态，但从不保存撤回码。这些信息仅保留在你的设备上，不包含在任何设置导出中。对于同意，只要同意有效，这些信息就会保留。撤回后，应用会在我们的服务器确认撤回或你确认已发送邮件后将其删除，并且最迟在你撤回后 90 天删除，即使撤回未能送达。撤回不影响撤回之前已进行的发布的合法性（GDPR 第 7 条第 3 款）。

你可以通过右下角的联系按钮（“写信给我们”）自愿向我们发送消息。届时，我们将处理你选择的咨询类型、你的消息正文、用于回复的电子邮箱地址，以及你所写页面的语言和路径。你无需提供姓名或账户。唯一目的是回复你的咨询。若你的咨询涉及 WhisPaste 的使用，法律依据为 GDPR 第 6 条第 1 款(b)项；其他情况下为 GDPR 第 6 条第 1 款(f)项（我们回复咨询的合法利益）。

数据通过 TLS 加密发送至我们的接口 api.whispaste.de。该接口运行在 netcup GmbH（Daimlerstraße 25, 76185 Karlsruhe, Germany）的服务器上，netcup 依据 GDPR 第 28 条作为我们的数据处理者行事；处理在德国进行。接口会将你的消息以电子邮件形式转发到我们的邮箱，且自身不存储其内容。一旦你的咨询得到解决，我们就会删除该邮件，最迟在 12 个月后删除，除非法定保存义务另有要求。

滥用防护: 为防止表单被用于垃圾信息，我们会限制每个发件人的消息数量。为此，我们从不以明文存储你的 IP 地址和电子邮箱地址，而仅以使用密钥生成的哈希值存储，并且仅保留到相应时间窗口结束为止（最多 24 小时，之后条目会自动删除）。一个隐藏的检查字段以及填写表单所用的时间，有助于识别自动化提交；为此不会收集其他数据。接口的技术日志不包含 IP 地址、电子邮箱地址或消息内容，只记录请求的类型和结果，并在 14 天后删除。法律依据为 GDPR 第 6 条第 1 款(f)项（防范滥用）。

除非你提交，否则不会传输任何表单数据。你可以随时反对此处理（GDPR 第 21 条），并要求我们删除你的消息；请写信至版权声明（Impressum）中列出的地址。“前往创意板”按钮会链接到我们在 VotePit（app.votepit.com）上的创意板，这是一项独立运营的服务，有其自己的隐私政策；只有当你打开该链接时，数据才会流向那里。
