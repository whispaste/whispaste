用于 Mac 的语音转文字：按下快捷键，开口说话，WhisPaste 会把你的话直接写在光标所在之处，适用于任何应用：邮件、备忘录、Slack、VS Code 或任何你打字的地方。

你的语音留在你的 Mac 上
两种设备端引擎负责转写：Whisper（Small、Medium 或 Large v3 Turbo，支持多达 99 种语言，在 Apple Silicon 上由 Metal 加速）以及速度尤其快的 Parakeet。模型只需一次性下载，之后转写可离线进行，你的音频从不离开你的 Mac。使用 OpenAI 或 Deepgram 的云端转写是可选的，使用你自己的 API 密钥，并直接发送给服务商，从不经过 WhisPaste 的服务器。无需账户。

智能模式
在粘贴前清理、缩短或翻译文字，可在 Mac 本地完成，也可通过 OpenAI 完成。之后也可以把它应用到过去的转写记录上。

用语音编辑选中的文字
在任何应用中选中一句话，按下选择快捷键，说出需要如何修改，例如“更友好一些”。WhisPaste 会原地改写选中内容。默认关闭。

语音片段
说出一个简短的触发词，WhisPaste 即可插入完整文本：签名、问候语、常用短语，或包含多个字段的交互式模板。

历史记录与导出
每条转写都保存在你的 Mac 上。可搜索、添加标签、置顶、归档和合并条目，用 PIN 保护历史记录，并导出为 TXT、Markdown、JSON、CSV 或 Word。

一次购买，而非订阅
没有订阅，没有时间限制，没有定期费用。WhisPaste 是开源软件（MIT 许可证），在 GitHub 上公开开发。你的购买直接支持它的开发。
