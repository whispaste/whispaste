WhisPaste CUDA acceleration module (optional download)
=======================================================

This archive is the optional NVIDIA CUDA acceleration module for WhisPaste.
It is not required: WhisPaste runs on the CPU and on Vulkan-capable GPUs
without it. When it is installed next to the WhisPaste application libraries,
whisper.cpp can run transcription on NVIDIA GPUs through CUDA.

Pack:     WhisPaste-CUDA-ggml-v1.9.5-cu12.8-r1
Contents: the ggml-cuda backend module, built from whisper.cpp / ggml v1.9.5,
          and the CUDA 12.8.1 runtime libraries it links (cudart, cuBLAS,
          cuBLASLt). The NVIDIA display driver, which provides the CUDA driver
          library, is not part of this archive and must be installed separately.
